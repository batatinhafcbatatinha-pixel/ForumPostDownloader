# Repository workflow rules

- Treat `upstream` (`SkyCloudDev/ForumPostDownloader`) as read-only.
- Never push commits, tags, branches, or any other changes to `upstream`.
- Never open, create, update, or merge a pull request targeting `upstream`.
- Never modify issues, discussions, releases, or workflows in `upstream`.
- Use `upstream` only to fetch and inspect newer changes.
- All changes and pushes must target the personal fork's `origin` remote unless the user explicitly gives a different instruction.
